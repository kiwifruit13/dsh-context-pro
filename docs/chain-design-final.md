> 本文件是 DSH-Context-Pro 链感知系统的**终局规格文档**，以设计方案与规划.md 的终局共识为唯一依据。
> 所有实现决策以本文件为准；旧设计（锚点语法）已下线并删除。
>
> 最后更新：2026-08-17

## 一、核心哲学

### 1.1 CoT 放权

**不替模型写行为规则，只给模型喂认知养料。**

模型在内部进行长链条、发散、多路径的深度思考（CoT），这部分**不做任何结构限制**。系统只做两件事：
1. 在 System Prompt 中注入五链图鉴，让模型**内化**这五种认知结构
2. 在模型回复末尾解析 JSON 快照，提取结构化结论

中间的辩论、逻辑继承、分岔处理——全部交给模型在黑盒里用 CoT 自行处理。

### 1.2 显性结构，隐性表达

模型在思考层面遵循链结构，但在最终输出给用户的文本中**不出现任何机械标签或节点名**。

```
❌ 机械感：【问题】项目延期。【原因】人力不足。
✅ 自然感：我们先来看当前卡住的现象：项目延期了两周。顺着这个往下挖，我发现根源在于人力被抽调了40%。
```

用户感受不到框架的存在，只感受到逻辑清晰、节奏自然的对话。

### 1.3 快照是记录仪，不是导航仪

快照只记录已确认或已推断的结论，**绝不限制推理**。模型可以自由进行反事实推演、多路径回溯、大胆假设，推理结束后把新结论增量映射到快照对应节点即可。

## 二、五维认知图鉴

### 2.1 序言：情绪即底色

情绪不是一条链，它是一种**调节器**。它影响的是"如何说"，而不是"说什么结构"。

| 情绪水位 | 语气策略 |
|---------|---------|
| 高水位（焦虑/急切） | 缩短句子，直给结论与动作 |
| 中水位（困惑/疲惫） | 放慢节奏，多给类比与陪伴感 |
| 低水位（冷静/疏离） | 保持密度直接上干货 |
| 情绪回落且有认知诉求 | 正常进入链的锚定 |

不必标注情绪，只需让语气与水位匹配。情绪是底色，链是骨架。

### 2.2 五链定义

人类思维在寻求确定性时，会把混沌信息折叠成五种链式结构。模型天生具备识别它们的能力——感知其形态、校准推理路径即可，**无需向用户提及链名**。

#### 因果链《溯源者》
- **结构**：痛点（What）→ 归因（Why）→ 破局（How）
- **触发**：异常/困境 + "为什么/怎么办"
- **口吻**：侦探感，先表象、层层剥根因、再给手术刀式方案
- **边界**：单纯感叹无归因意图时不套用，回到倾听

#### 逻辑链《架构师》
- **结构**：前提 → 约束推演 → 收敛结论
- **触发**：权衡/假设/"如果…那么…"
- **口吻**：冷峻去情绪化，"因为 1、2、3，所以 A"；前提存疑必须注明结论依赖该前提
- **边界**：对方只要生活妙招时勿刻板说教

#### 操作链《手艺人》
- **结构**：启动 → 步骤序列 → 终态
- **触发**：动作动词/"先…再…"/无从下手求手把手
- **口吻**：说明书，编号+具体动词，关键步骤标注可能的坑
- **边界**：战略方向讨论无动作序列时不套用

#### 叙事链《说书人》
- **结构**：初始 → 冲突介入 → 认知颠覆（转折）→ 新平衡
- **触发**：具体年月/状态反转/回顾唏嘘
- **口吻**：允许画面感，转折点必须高亮——它是信息最高密区
- **边界**：无起伏的流水账属时间链，不属叙事

#### 时间链《预言家》
- **结构**：遗迹（过去）→ 镜像（现在）→ 概率（未来）
- **触发**："以前/现在/以后"三段对比、关注持续性后果
- **口吻**：标注时间刻度（短/中/长期），说明现在由哪些过去堆叠而成
- **边界**：只讨论明天做什么属操作链

### 2.3 融合法则

现实话语常是五种结构的混合体：

1. **主次分明**：锁定得分最高且用户最迫切的一条为主链
2. **逻辑嫁接**：在主链的回复中，可以随时穿插其他链的节点（如操作步骤里插一句时间提醒）
3. **链间化学反应**：主链推进中常自然触发他链，交叉点往往是认知密度最高的地方。四种经典反应方程式及嗅觉催化机制的完整推演见 `融合进阶.md`
4. **嗅觉催化**：锁定主链后给自己 3 秒嗅觉停顿——腐蚀味/阻力味/空洞味，闻到就追踪到底，没闻到就走单链
5. **逃逸舱**：五链得分均低于 30% 且纯寒暄/情绪宣泄时，不提取任何结构，共情陪伴，等用户抛出第一块认知砖头

> 链间化学反应不进快照——快照只记主链 nodes，化学反应只反映在正文的信息密度上。

## 三、提取通道：末尾 JSON 快照

### 3.1 协议

模型在回复正文结束后，另起一行，用一行 JSON 输出当前主链终态：

```json
{"chain":"因果链","nodes":{"问题":"","原因":"","方案":""}}
```

nodes 键随链型：

| 链 | nodes 键 |
|----|---------|
| 因果 | 问题 / 原因 / 方案 |
| 逻辑 | 前提 / 推理 / 结论 |
| 操作 | 动作 / 步骤 / 结果 |
| 叙事 | 开端 / 发展 / 转折 / 结局 |
| 时间 | 过去 / 现在 / 未来 |

未识别主链时输出：`{"chain":"null"}`

### 3.2 节点值三形态

| 形态 | 示例 | 场景 |
|------|------|------|
| **字符串** | `"需求失控（置信度78%）"` | 推断结论，可括注把握度 |
| **分叉** | `{"ai":"人力不足","user":"需求混乱"}` | 与用户路径分歧，并行记录不二选一 |
| **合流** | `{"value":"优先级裁剪","from":["ai","user"],"confidence":0.8}` | 双方推论在下游重叠，声明继承 |

### 3.3 supersede 回溯

推翻旧主链时（新证据/用户否定），显式声明回溯：

```json
{
  "chain": "因果链",
  "supersede": { "root": 1, "reason": "新证据：人力充足，需求混乱" },
  "nodes": { "问题": "项目延期", "原因": "需求失控" }
}
```

被推翻的旧结论保留为"曾以为"（负向锚点）：对比论证时可引用，但不得作为当前推理前提。

### 3.4 用户不可见

JSON 快照行由系统 hook 在提取后自动剥离，用户看到的回复正文中不存在该行。

## 四、认知豁免权（最高优先级）

快照和提取协议遵守以下豁免规则：

1. **不限制推理**：反事实推演、多路径回溯、大胆假设均可自由展开
2. **缺口填充**：缺口可按内部推断填充并顺带说明把握度，不必中断去问用户
3. **被推翻的结论不删除**：保留为"曾以为"（supersede），供后续对比论证引用
4. **结构是记录仪**：推理结束后把新结论增量映射到快照对应节点即可

---

## 五、纪律

1. 正文用自然语言表达，不在输出中添加任何 `[标签]` 或 `【节点名】`——用户感受不到框架的存在
2. 只在触及对应推理结构时在末尾输出 JSON 快照，不为打标而打标；拿不准就输出 `{"chain":"null"}`
3. 用户对话中触及的链，由模型在回复时**补标**（模型是唯一打标者）
4. 好的结构让用户感到通畅，而不是看到框架：正文自然表达，勿机械使用节点名词作抬头

## 六、系统架构

### 6.1 数据流

**链协议模式（chains.enabled && injectProtocol）—— CoT 放权：**

```
用户输入
    │
    ▼
agent/pre-step (waterfall)
    │  零干预：不 SELECT、不 REFACTOR、不 INJECT、不 MEASURE
    │  系统只做两件事：
    │    1. System Prompt 中已注入五链图鉴（prompt.ts）
    │    2. 模型回复末尾解析 JSON 快照（hook.ts）
    ▼
模型生成回复（CoT 自由推理，图鉴已内化）
    │
    ▼
回复末尾附加 JSON 快照行
    │
    ▼
session/event → hook.ts
    ├─ 解析末尾 JSON 快照 → 更新 ChainGraph
    └─ 剥离 JSON 快照行（用户不可见）
    │
    ▼
用户看到纯自然语言回复
```

**非链模式（旧版上下文整形器，chains.enabled=false）：**

```
用户输入
    │
    ▼
agent/pre-step (waterfall)
    │
    ├─ SELECT：从消息选文本候选
    ├─ REFACTOR：重组为带引用标注的注入块
    ├─ INJECT：追加进 messages（user 消息，source=plugin）
    └─ MEASURE：度量注入块质量 → 日志
    │
    ▼
模型生成回复
    │
    ▼
用户看到回复 + 注入的上下文片段
```

### 6.2 核心组件

| 组件 | 职责 |
|------|------|
| `prompt.ts` | 图鉴提示词段，注入 systemPrompt |
| `hook.ts` | 监听 assistant/message，提取末尾 JSON 快照 + 剥离 JSON 行 |
| `snapshot.ts` | 解析快照 JSON + 合并到 ChainGraph（含 confidence 提取） |
| `graph.ts` | ChainGraph 演化算法 |
| `index.ts` | ChainIndex 临时存储 + 生命周期 |
| `guide.ts` | 脉络导览（GPS 坐标/轨道图/缺口） |
| `candidate.ts` | 链节点 → SELECT 候选（仅非链模式；链协议模式下废弃） |
| `prestep.ts` | waterfall 拦截器（链协议模式：零干预；非链模式：SELECT→REFACTOR→INJECT→MEASURE） |

> **洞察引擎相关组件**（`insight.ts`、`types.ts` 归因契约、`auth.ts`、`openapi.ts`、`metrics.ts`、`client.js`、HTTP 路由）已迁移至独立架构文档：[`insight-architecture.md`](./insight-architecture.md)。

### 6.3 生命周期

```
新会话开始 → ChainGraph 创建
每轮 assistant/message → hook 提取快照 → ChainGraph 演化
会话结束/删除 → ChainGraph dispose（不残留）
```

链是**会话内临时索引**，非长期记忆。跨会话检索用 agent-memory。

## 七、与旧设计的关系

### 7.1 锚点语法已下线

旧设计引导模型在正文中输出 `[因果@1]` 标签作为提取通道。终局共识将其下线，原因是：
- 标签破坏阅读体验，与"隐性表达"原则冲突
- 模型在 CoT 中已具备结构感知能力，无需显式标签辅助
- 末尾 JSON 快照作为提取通道更干净、更可靠

### 7.2 解析器已删除

`parser.ts`、`extractor.ts` 等锚点解析组件已删除，原因：
- 模型已被明确告知不输出任何 [标签]（prompt.ts 纪律第一条）
- 旧会话日志随会话删除而消失，链是会话内临时索引
- Git 历史中完整保留，如需回滚可从 `git log` 恢复

### 7.3 被 CoT 放权替代的早期设计

| 早期设计 | 被替代原因 |
|---------|-----------|
| 强制链式结构生成（标题加粗） | 改为自然表达，交给 CoT |
| 主动问用户补全缺口 | 改为推断+置信度标记 |
| 逻辑自洽性审查硬规则 | 交给 CoT 自行判断 |
| 主动转链提案模板 | 交给 CoT 自然发生 |
| 三段式辩论协议 | 交给 CoT 自行处理 |
| 独立情绪链 | 升维为"情绪即底色" |

## 八、配置选项

```yaml
config:
  chains:
    enabled: true          # 开启链感知（默认 false）
    injectProtocol: true   # 注入图鉴提示词段（让模型内化五链结构）
    stripAnchors: true     # 注入前剥离残留锚点（兼容旧会话）
    maxNodesPerChain: 20   # 每链节点上限（防演化失控）
```
